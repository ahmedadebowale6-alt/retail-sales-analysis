# Retail Sales Analysis

A data-analysis project using MySQL, Microsoft Power BI and Excel to explore retail sales performance and present clear, decision-focused insights.

## Project Overview

This project examines retail sales data to understand sales performance, product trends and customer purchasing patterns. The analysis combines SQL for querying and cleaning data, Excel for initial exploration, and Power BI for interactive visualisation.

## Objectives

- Clean and prepare retail sales data for analysis
- Explore sales trends across products, categories and time periods
- Identify useful business insights that can support decision-making
- Create an interactive Power BI dashboard for clear reporting

## Tools Used

- MySQL
- Microsoft Power BI
- Microsoft Excel

## Analysis Process

1. Reviewed and prepared the data in Excel
2. Used MySQL to query, clean and explore the dataset
3. Identified trends and business-relevant patterns
4. Built Power BI visuals and dashboards to communicate findings clearly
